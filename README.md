# Expense Tracker

A simple Expense Tracker project built using **HTML, CSS, and JavaScript**.

This project helps users add their daily expenses, select an expense category, view their expense history, and calculate total expenses.

## Live Demo

[Click here to view Expense Tracker](https://expensetracker-hzclqeewe-aditya-rana.vercel.app/)

## Features

- Add new expenses
- Enter expense name and amount
- Select expense category (Food, Travel, Shopping, Other)
- View expense history
- Calculate total expenses
- Delete expenses

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Enter the expense name.
2. Enter the amount.
3. Select a category.
4. Click on Add Expense.
5. View your expenses and total amount.
6. Click Delete to remove an expense.

## Note

This is a beginner-level project created for JavaScript practice. Expense data is stored temporarily and will reset when the page is refreshed.
